# Godot 4 and GDScript pitfalls (each one has cost time here)

## Network play (see `11_network_play.md`)

- **A child added later does not take its parent's authority.** `set_multiplayer_authority` on a node reaches the children it has
  then. A `MultiplayerSynchronizer` added afterwards stays with peer 1, so on a client the host overwrote the client's own wizard.
  Set the synchronizer's authority before adding it (`Wizard.share`).
- **`--fixed-fps` with `--headless` runs faster than the clock.** Two copies that talk over the network then time out: a 40 second
  wait ended in two real seconds. Run network tests in real time.
- **Do not free a node another machine still sends to.** A likeness that freed itself after its death fade, while the host's wizard
  still existed, gave "Node not found ... /Sync" on every packet. Likenesses only fade; they go with their scene.
- **Say you are leaving a scene before you leave it.** A machine that frees its scene first gets the packets already sent to it
  ("Ignoring sync data ... missing node"). `_leave_network_scene` runs as the screen fades.
- **`Input.parse_input_event` does not move the pointer** that `get_global_mouse_position` reads; `Input.warp_mouse` does.
- **Typed arrays do not survive an rpc.** An `Array[int]` argument arrives as a plain `Array`: take `Array` and `assign` it.

## Rendering

- **The white rectangle bug.** `var tex := load(...)` inside `_draw()`, used with `draw_texture`: the texture is
  freed when the function returns, before the frame renders, and draws as a white rectangle. Always use
  `preload()` constants or a member variable or cache (`Fx.tex`, `PixelFx.frames`).
- **Texture filter enum.** Project setting `default_texture_filter`: 0 Nearest, 1 Linear, 2 Nearest Mipmap,
  3 Linear Mipmap. The game uses 2. Mipmaps are generated by default (`[importer_defaults]`).
- **Materials.** A CanvasItem's material is not inherited by its children unless `use_parent_material` is true.
  Additive glow on a parent doesn't make child sprites additive.
- **`modulate` and shaders.** In a `canvas_item` shader, `COLOR` in `fragment()` already includes the texture.
  Carry the vertex `COLOR` through a varying if you need the plain modulate (see `mob.gdshader`).
- **Texture repeat.** Filling a polygon or rect with a repeating pixel texture needs
  `texture_repeat = CanvasItem.TEXTURE_REPEAT_ENABLED` on the drawing node. Then use
  `draw_texture_rect(tex, rect, true)`, or polygon UVs greater than 1.
- **Parallax2D.** Use `scroll_scale.y = 1`, or layers drift away from where you placed them. Keep
  `repeat_size` equal to the texture width times its scale.
- **CanvasLayer order:** sky -20, HUD 3, spellbook 5, ritual box 10, debug panel 20. Anything on a CanvasLayer
  ignores the camera.
- **Pixel fonts.** Load them as `FontFile` and set `antialiasing = TextServer.FONT_ANTIALIASING_NONE`. A
  variable typed `Font` doesn't expose that property.

## GDScript

- **"Cannot infer type".** `var x := some_dict["key"]` and `var x := array_of_variants[i]` fail to parse. Write
  `var x: float = ...`.
- **Autoloads and `-s`.** Scripts run with `-s` (extending SceneTree) can't see autoloads like `Sfx`. Make a
  scene instead (the showcase does).
- **Test timing.** In a SceneTree test, nodes' `_ready` hasn't run during `_initialize`. Do checks in `_process`.
- **Private fields.** Don't read another script's `_underscore` variables, even though `node.get("_x")` works:
  give the script a public property or method instead (see section 9 of `CLAUDE.md`).
- **New `class_name`.** A new global class isn't known until `godot --headless --path . --import` has run; until
  then other scripts fail to parse with "Identifier not declared".
- **What `-s` scripts can load.** A `-s` test that preloads a script which mentions an autoload (even indirectly,
  through a class it uses) fails to compile. Keep the gesture code free of spell and autoload references.
- **Lambda captures.** Lambdas capture variables by value at creation. Use arrays or dictionaries as mutable
  boxes (see `showcase.gd`).
- **Freeing during iteration.** A body can leave the `mobs` group mid-loop when your damage kills it. Read
  `is_in_group` **before** calling `hurt` (see the old Fire Nova).
- **Deferred changes.** Changing collision state inside physics callbacks needs `set_deferred`.

## Physics

- **One-way platforms** (layer 16) only stop motion from above. For "is this covered from the sky", raycast from
  the sky downward.
- **Area2D defaults** to layer 1. A Barrier with mask 1 sees shots (areas on layer 1) and terrain bodies.
- **Flyers** have collision mask 0 and are moved by hand; check walls with raycasts.
- **Rescaling an Area2D re-fires `area_entered`.** Changing a node's scale rebuilds its shapes, and anything already
  inside is reported as entering again. A melting icicle took two slices from one fireball until it remembered which
  shots had struck it. Guard one-time hits with a set of instance ids.
- **Fast things and thin ground.** Move a fast shot by hand and raycast from its old position to its new one each
  frame (see `lava_ball.gd`), so it can't skip through a thin platform between frames.

## Startup and loading

- **Logs.** Godot's file log once grew to 270 GB (`godot.log` under the user data folder) when stuck headless
  test runs printed errors every frame, and made the game slow to start. File logging is off in
  `project.godot` (`file_logging/enable_file_logging.pc=false`). Always run tests with a time limit
  (`--quit-after`, or `timeout` in the shell) and kill leftover Godot processes.

- **Don't load every asset at launch.** `Sfx` used to decode all ~100 sounds in `_ready`, which added many seconds
  before the window showed. It now keeps paths and loads a sound the first time it plays. Do the same for any big
  set of assets.
- **Name clashes.** A local variable named `size` inside a Control's `_draw` hides the `size` property and fails
  to compile ("Identifier not found"). Use `box` or similar.

## Labels and containers

- **Collapsing labels.** An autowrapping Label has zero minimum width inside an HBox, so its text collapses to
  one letter per line. Turn autowrap off for short words (the old Enter keycap bug).
- **Growing containers.** Containers grow to fit their children. For fixed-size pages, use plain Controls with
  `clip_contents` and fixed sizes, and split content across pages.

## Python tooling on this machine (Windows)

- **numpy int32 overflow.** `np.arange` defaults to int32. Multiplying by 48000 overflows silently. Use
  `dtype=np.float64`.
- **pip.** The default index is a GitLab mirror. Use
  `pip install --isolated --index-url https://pypi.org/simple`.
- **Shell heredocs.** Long bash heredocs containing apostrophes can fail in this tool environment. Write the
  Python edit to a file and run it.
- **Downloads.** Use `python -I` for anything that reads downloaded files, and keep downloads in their own scratch
  folder.
