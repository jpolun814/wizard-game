### G2. What the research found, 2026-11-06 (sources: godotsteam.com blog 2026-03/04, partner.steamgames.com/documentation/dedicated_servers, steamdb.info/app/480/config)
- The owner does NOT want the player-hosted version: a headless dedicated server only.

- Conclusion: the free 480 plan only fits player-hosted games. For a headless server the options are: (a) own App ID plus GodotSteam Server; (b) skip Steam: put the server where it is reachable (an AWS machine with a public address) and join by address, which the game already does.
- Recommended: (b). Steam is only a way round a home router; a cloud server has no such router. Revisit Steam only for friend lists/invites or a store release.

## H. The server plan (decided 2026-11-06; nothing coded)

This touches every spell, the AI and the liquids, so move things over in parts: damage, deaths, page reading and the result first, then the rest. Competitive ranking (section F) only counts once this is done.
- **Before either step:** understand the failing `net_match_check` (chapter 15); both steps rest on the same code.
- **Then the cloud:** the same server process on an AWS machine with a public address; measure CPU and memory of one headless match first to choose the machine size.
- **Builds (decided 2026-11-06):** two applications. The client is the existing Windows export (`export_presets.cfg`, "Windows Desktop", `build/WizardGame.exe`). The server uses Godot dedicated-server export (the preset flag `dedicated_server`, now false), which strips art and sound. The owner is fine running two programs at once.
